# Teen Preneur 🚀

Teen Preneur is a comprehensive platform designed to empower teenagers (ages 13-19) to transform their entrepreneurial ideas into impactful businesses. Inspired by successful incubators like Y-Combinator, Teen Preneur provides structured mentorship, resources, and community support for cause-based entrepreneurship.

## 🌟 Platform Overview

Teen Preneur helps young entrepreneurs:
- Build and validate business ideas
- Connect with experienced mentors
- Access structured incubation programs
- Track business metrics and revenue
- Build portfolios for college applications
- Create meaningful social impact

## ✨ Key Features

### 1. **Mentor Hub**
Connect with experienced entrepreneurs and industry experts who provide:
- One-on-one mentorship sessions
- Specialized guidance in technology, social impact, e-commerce, and creative industries
- Expert advice on overcoming business challenges
- Networking opportunities

### 2. **Alumni Network**
Learn from successful Teen Preneur graduates:
- Success stories and case studies
- Peer support and collaboration
- Monthly community meetups
- Resource library and exclusive content
- Access to collaboration opportunities

### 3. **Startup Incubator**
Comprehensive 12-week program to transform ideas into businesses:
- Structured curriculum from ideation to growth
- Business planning and validation
- Product development support
- Marketing and sales training
- Demo Day pitch opportunities
- Funding connections

### 4. **Revenue Tracking**
Monitor your business growth with powerful analytics:
- Revenue and expense tracking
- Performance metrics and KPIs
- Growth visualization with charts
- Goal setting and milestone tracking
- Integration with payment processors and e-commerce platforms

### 5. **Profile & Portfolio**
Build a compelling entrepreneurial portfolio:
- Document your journey and achievements
- Showcase projects with metrics and impact
- Highlight skills and recognition
- Create professional profiles for college applications
- Share testimonials and media

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (with App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: React 19
- **Build Tool**: Turbopack

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/apattnay/teen-preneur.git
cd teen-preneur
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

### Available Scripts

- `npm run dev` - Start development server on http://localhost:3000
- `npm run build` - Build the application for production
- `npm start` - Start the production server
- `npm run lint` - Run ESLint to check code quality
